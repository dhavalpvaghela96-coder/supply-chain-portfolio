Summary

This simulation used DMAIC to find out why Web Camera has a 58% late delivery risk. Through ABC classification and root cause analysis I found that the absence of a reorder point, combined with long supplier lead times, is causing stock to run out before anyone notices. Web Camera is a B item contributing $240,496 in revenue but carrying a disproportionately high delivery risk. The root cause is no reorder point set for this SKU, meaning stock runs out with no trigger to reorder.

Problem Statement

Looking at 50 product categories in this dataset, the Camera category stands out as the biggest business risk. It has the highest revenue at stake at $240,500 and a late delivery risk score of 0.58, which puts it in the top 5 across all categories. Golf Bags and Carts has a higher risk score at 0.69 but only $9,400 in revenue, so it is a much smaller problem for the business. This analysis focuses on Web Camera because reducing late delivery risk there protects the most revenue.

Root Cause Summary

The main problem is that no one has set a reorder point for Web Camera. This means nobody gets a warning when stock is running low, orders keep coming in but there is nothing left to ship. On top of that, cameras are likely sourced from overseas suppliers which means it takes longer to restock. So even if a reorder point is set, if it does not account for that longer wait time, stockouts will still happen.
